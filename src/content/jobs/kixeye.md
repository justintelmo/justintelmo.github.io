KIXEYE was my second job out of school, and my second job where PHP was the back-end language of choice. The majority of our game's backend logic was written in PHP, but we also supported a live battle simulation server that was written in C++. Our game's client code was written mostly in ActionScript 3, with a small chat service written in Python. My work here was mostly feature work, ranging from small refactors to tentpole features like supporting new content updates and helping create new game modes. Two noteworthy things to mention about my time here: I helped upgrade our PHP stack from PHP 5 to PHP 7.2.4, and I helped improve the security of our game by moving critical game features from being client-authoritative to server-authoritative.
