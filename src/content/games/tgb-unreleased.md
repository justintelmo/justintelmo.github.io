This was an unannounced multiplayer Unity game at The Game Band. I was the senior engineer on the back end and the main point of contact with our back-end vendor. My work focused on scaling the systems that would support the game's multiplayer features. It was also my first time working in Unity on a professional team.

## Key features

### Back end on an external platform

We built the game's back end on top of an external backend-as-a-service company. I owned that integration and worked with the vendor directly. With their help, we built **Kotlin** microservices for achievements and purchases.

### CI/CD pipeline

I built the build pipeline on **Jenkins** so the team could build and deploy the game and its services automatically. We leveraged **AWS S3** to store build artifacts from release builds for archival and debug purposes. I was also tasked with making sure the **Jenkins** environment ran smoothly and securely on an **AWS EC2** instance.
