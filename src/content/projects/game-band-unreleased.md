This was an unannounced multiplayer Unity game at The Game Band. It was in development for about a year before it was shelved. I was the senior engineer on the back end and the main point of contact with our back-end vendor. My work focused on scaling the systems that would support the game's multiplayer features. It was also my first time working in Unity on a professional team.

## Key features

### Back end on an external platform

We built the game's back end on top of an external backend-as-a-service company. I owned that integration and worked with the vendor directly. With their help, we built Kotlin microservices for player voting, achievements, and purchases.

**Tech:** Kotlin, Pragma, Docker, AWS

### CI/CD pipeline

I built the build pipeline on Jenkins so the team could build and deploy the game and its services automatically.

**Tech:** Jenkins, Docker, AWS
