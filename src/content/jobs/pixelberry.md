I joined the Pixelberry team to work on StoryLoom shortly after my time with EA / Glu Mobile came to an end. StoryLoom was a mobile store front-end written in TypeScript that communicated to a core game layer written in Unity C# using JSBridge. This was where I was able to work in modern TypeScript for the first time, alongside a team of incredibly talented web engineers. This was my first job that was not necessarily inside the games space itself, although the work felt very similar. Our front-end was written in React, and our back-end was written in Node.js. I was able to leverage my experience working full-stack in games here, balancing features that required client work and writing the server-side code to facilitate the necessary business logic.
