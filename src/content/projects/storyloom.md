StoryLoom is a mobile app from Pixelberry Studios for interactive stories. The storefront was a TypeScript web app that talked to a core game layer written in Unity C#. I joined as a full-stack engineer and helped take it out of beta to a global launch on iOS and Android. It was my first time working in modern TypeScript, alongside a team of strong web engineers.

## Key features

### A lighter mobile client

I helped build the mobile client in Vite and React. It cut the app's size by more than half.

**Tech:** TypeScript, React, Vite

### Node.js services

I built Node.js microservices on AWS and Docker that served thousands of daily players. I often wrote the client feature and the server code behind it.

**Tech:** Node.js, TypeScript, AWS, Docker

### Bridge between web and Unity

I maintained the JSBridge layer that let the web client and the native Unity clients talk to each other.

**Tech:** TypeScript, Unity, C#
